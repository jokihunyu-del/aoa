# AOA — Always On Fiber

AOA delivers high-speed symmetric fiber built for developers, AI teams, and smart businesses across Nairobi, Kahawa West, and wider East Africa.

## Features
- Symmetric fiber uploads and downloads
- AI and ML workload optimized
- Simple daily / weekly / monthly pricing
- 99.9% uptime
- Local support based in Kahawa West and Nairobi

## Getting started

Requirements: Node.js 18+, npm

```bash
npm install
npm run dev
npm run build
npm run preview
```

Project layout:
- `src/App.jsx` main marketing page
- `src/index.css` base styles
- `vite.config.js` config for dev, build, and tests
